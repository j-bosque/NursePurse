# NursePurse Review

A study app built from the MDC2 Module 5 (Acid–Base), MDC2 Module 6 (Upper GI & Nutrition) and NUR2474 Module 7 (Endocrine, Reproductive & Urinary Meds) lecture decks.

Open `index.html` in any web browser. No install needed.

- **Practice**: multiple-choice quiz. Pick how many questions (5–50, all, or a custom number) and which modules.
- **Topics**: choose one or more of 12 topics. Each card shows your accuracy so you can find weak spots.
- **Game**: timed rounds with speed points, streak bonuses, 50/50 and +10 s lifelines, levels, badges and a high-score board.

Questions live in `questions.js`. To add one, copy a `Q(...)` line and put the correct answer first; the app shuffles the choices.
